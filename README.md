# LLM Playground

[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

This repo is a personal space for prototyping and experimenting with large language models (LLMs), focusing on prompt design, RAG, lightweight apps using tools or utilities that are fun (and useful) to build.

## 🧪 Experiments
| Module           | Description                                              | Status     |
|------------------|----------------------------------------------------------|------------|
| [`prompt_gallery`](./prompt_gallery/README.md) |  Curated prompts + automated evaluation across LLMs | ✅ Completed |

## 🧰 Tools & Stack
- Python 3.12
- Jupyter Notebooks – Quick evaluations and analysis
- LLM APIs – Groq
- `pipreqs` – Auto-generating `requirements.txt`
- `dotenv` – Manage API keys and paths
- Logging – Track prompt runs and outputs

## 🔄 Status
This repo is under active development.  
New prompt sets, experiments, and utilities are added iteratively.
